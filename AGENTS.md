# AGENTS.md

Guide for AI agents working in this repo: the public StaffOps Helm charts, served at
`https://staffops.github.io/helm-charts/`. Human-facing docs: [README.md](README.md) and [docs/](docs/index.md).

## Branches

| Branch | Use |
|---|---|
| `main` | Source of truth. A merge that changes `charts/**` releases every bumped chart |
| `feat/*`, `fix/*` | Work branches, merged through a pull request (lint-test runs on it) |
| `gh-pages` | Generated by chart-releaser (`index.yaml`, `.tgz`) and the docs site. Never edit by hand |

## Commands

Helm and chart-testing run in Docker, matching CI (`.github/workflows/lint-test.yaml`):

```bash
docker run --rm -v "$PWD:/work" -w /work alpine/helm:3.14.0 lint charts/<chart>
docker run --rm -v "$PWD:/work" -w /work alpine/helm:3.14.0 template r charts/<chart>
docker run --rm -v "$PWD:/data" -w /data quay.io/helmpack/chart-testing:latest \
  ct lint --chart-dirs charts --target-branch main
git config core.hooksPath .githooks   # once per clone: the docs-with-code gate
```

CI runs `ct lint` and `ct install` on a kind cluster for changed charts (`anomaly-detection` is
excluded from `ct install`; `ct lint` still covers it).

## Rules

- **English only**: chart READMEs, docs, CHANGELOGs and commits.
- **Conventional Commits** with the chart as scope (`feat(generic): ...`, `fix(aigent-squad): ...`).
- **Release = version bump**: bump `version` in `Chart.yaml` (SemVer), `appVersion` when the app
  changed, and the chart's `CHANGELOG.md` when it has one. Merge to `main` and the release workflow
  publishes it.
- **Docs ship with the chart**: the pre-commit hook rejects a change to `templates/`, `values.yaml`
  or `Chart.yaml` without that chart's `README.md`. Root `CHANGELOG.md` `[Unreleased]` and
  [docs/handoff.md](docs/handoff.md) change in the same PR.
- **Secrets are never committed**: values reference Secret names (`existingSecrets`,
  `externalSecrets`), never values.

## Pitfalls

| Pitfall | What to do |
|---|---|
| `ct lint` validates `maintainers` names against the GitHub users API | Use a real GitHub login (`StaffOps`) |
| A merge whose release job fails leaves the chart unpublished (aigent-squad 0.9.6, GitHub API 500) | Check `gh run list -w "Release Charts"` after a merge; re-run it (the workflow has `workflow_dispatch`) |
| Root README version badges are hand-written and drift | Update the README table with the bump |
